🎬 Get Your Free YouTube API Key (2 min setup)

This dashboard needs a free YouTube API key to fetch your channel's public videos. It's completely free and takes just a few steps.

  1. Go to Google Cloud Console
  2. Click "Create Project" (top left dropdown)
  3. Name it "YouTube Dashboard" and click Create
  4. Click "+ Enable APIs and Services"
  5. Search for "YouTube Data API v3" and click it
  6. Click "Enable"
  7. Click "Create Credentials" → Choose "API Key"
  8. Copy your new API key and paste it below
